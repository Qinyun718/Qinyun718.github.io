后续评测方向

从 Coding，走向更广的 Working。

在已有评测工作之上，继续探索多轮与长程开发，并把领域知识的搜集、理解与应用纳入更广的工作任务。

Coding

继续做深 Coding

继续研究反馈如何真正推动修复，以及 Agent 如何在更长的开发过程中保留先前约定、发现旧缺陷并完成交付。重点放在连续过程中的判断与验证。

  • 收到新要求或问题反馈后，能否修到关键处，并保留已有行为？
  • 任务跨越多轮与多个版本时，能否发现早期错误，并在最终交付前验证完整目标？

Working

扩展到 Working

计划以 Coding 为基础扩展 Working 评测：保留编码与查询等任务，同时更多考察 Agent 如何搜集领域资料、理解业务概念和适用条件，再把这些知识用于行动与交付。

  • 面对陌生领域，能否找到相关资料，理解概念，并区分哪些信息适用于当前任务？
  • 能否把领域知识转成合理的工作步骤，并用可核查的结果检验自己的判断？

拟探索的工作过程

从具体工作目标出发，串起知识、判断、执行与验证；验证发现缺口时，再回到需要补充的环节。

  1. 1

    明确工作目标

    交付物与约束

    →
  2. 2

    搜集领域知识

    资料、业务口径、已有流程

    →
  3. 3

    理解并形成判断

    概念、证据与适用条件

    →
  4. 4

    执行与交付

    按需编码、查询或使用其他工具

    →
  5. 5

    验证与修订

    结果符合目标，判断有据可查

↶验证发现缺口后，补充知识或调整方法
